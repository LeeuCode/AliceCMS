# AliceCMS
##Multipurpose Business CMS PHP

AliceCMS is a multi-purpose content management system built using the Codeigniter framework, so it has strong protection and high performance, you can use it to manage your websites, business, web hosting, and much more.

AliceCMS is highly flexible in use and development. We have taken all of our parts into a flexible, easy-to-use script. This is reflected in the ease of control of the Script Control Panel, and the system is protected from CSRF and XSS attacks. Built-in advanced log-in system that has the password recovery feature if you forget the password and remember the login feature.
