AliceCMS is a multi-purpose content management system built using the Codeigniter framework, so it has strong protection and high performance, you can use it to manage your websites, business, web hosting, and much more. AliceCMS is highly flexible in use and development. We have taken all of our parts into a flexible, easy-to-use script. This is reflected in the ease of control of the Script Control Panel, and the system is protected from CSRF and XSS attacks. Built-in advanced log-in system that has the password recovery feature if you forget the password and remember the login feature.

Introduction

To complete the installation process correctly, you must follow these steps:-
1. Unzip the Alicecms.zip file.
2. The file will produce a folder with two folders, the Alicecms folder, the script, and the Documentation folder.
3. Take the Alicecms folder to your hosting and follow these steps:-

Installation

1- Step one :-

Enter to your site link and suppose it www.your-site.com, you will be automatically redirected to the following installation page

Requires you to provide all the requirements for the system to work well, so follow the steps correctly, when the x appears in red, it requires you to process the error or provide the requirement.

 

2- The second step:-

requiring you to enter database data, be careful when you enter database data, AliceCMS uses MySQL databases 

 

3- The third step:-

requires you to enter the name of the site, description and keywords, it is the SEO settings (Search Engine Optimization), but you can enter the description and keywords from the site settings later.

 

4-Step Four:-

You have successfully installed the program, click on Sign in now 

 

 

Registration System

To sign in to your site, visit the site link with auth/login such as:-Www.yoursite.com/auth/login will be directed to that page

 

The system is built into a very powerful membership registration system and has many advantages, if you forget the password you can retrieve it by sending a link to your email as follows

 

You can control the addition of users and edit and delete them via the user Control page

 

You can add a new user by clicking on the Add New button

 

When you add a new user that gives it a normal user permission, you can modify the permission by using the Modify user page

 

Modules

1- Dashboard :-

In this module a summary of the modules is shown in the script

 

2- Pages :-

In this module the pages are controlled add, modify, and delete pages from them

    

 

3- Menus :-

Using this module, you can control the menus from Add, Edit and Delete, and you can customize where the list appears

  

 

4- Slideshow :-

This module is used to add, modify, and delete slides.

  

 

5- services :-

This module is used to manage services from adding, modifying, and deleting and viewing all services.

  

To create a new service, click on Add New.

AliceCMS Supports icons Font-awesome You can easily choose icons now with it.

 

6- Portfolios :-

This module controls viewing, adding, and modifying your Portfolios

To add a new portfolio, click on Add New

You can add snapshots to your infinite project to illustrate the work you have done, or that you offer, by clicking on Add New

When you click on the image upload icon, a pop-up window will appear to upload a picture and choose a suitable image 

 

7- Price Plans :-

This module is used to control the price plans of your site.

Price plans are designed in an easy-to-use manner, so you can adjust the entire plan during the build process only

To add plan features or items, click on Add Plan Item 

8- Team :-

This module is used to manage team members from adding, modifying, and deleting.

You can add an unlimited number of members just click on the Add New button

This section will appear in the website as follows:-

 

9- Testimonials :-

This module is responsible for controlling every testimonials of the site by adding, modifying, and deleting 

  

 

10- Partners :-

This module is used to manage partners from adding, modifying, and deleting.

You can add an unlimited number of partners just click on the Add New button

 

11- FAQ :-

This module is used to manage FAQ from adding, modifying, and deleting.

  

You can add an unlimited number of FAQ just click on the Add New button

 

12- Subscribers :-

This module is used to manage subscribers from exporting or deleting subscribers.

 

13- Section Layout :-

This module is used to manage site sections layout from addresses and images 

 

14- Settings :- 

This module is responsible for managing site settings from logo and Fivicon, keywords, site descriptions, and social media.
